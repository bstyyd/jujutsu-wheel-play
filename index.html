当前术式说明

晚期开局会载入此前的世界进度，不领取跳过章节的奖励。新周目增加敌人强度，开局继承加成上限 30%，不直接叠加上一轮的最终属性。

怎么玩

  1. 选择随机抽取，或自定义身份、术式、属性和起始章节。
  2. 每天安排一次修炼、狩猎或整备，也可继续使用行动转盘。
  3. 在角色下方打开咒具库；剧情战与狩猎胜利解锁武器，每次可携带一件。
  4. 剧情日进入任务；先看目标和敌人预告，再决定进攻或防御。
  5. 通过第120天最终挑战后，可进入更强的下一周目。六个槽位各自保存。
旧版规则（旧档适用）
▍玩法说明
① 进入游戏后依次转动 12 个基础设定转盘（身份 → 时间点 → 年龄 → 性别 → 颜值 → 生得术式 → 咒力总量 → 咒力操控 → 体术 → 体质 → 咒力效率 → 成长值），转盘将自动跳转。
② 自宿傩受肉虎杖（第 0 天）起，至新宿决战（第 120 天）终。非剧情日转动「行动转盘」修炼成长或狩猎咒灵；抵达剧情日自动进入剧情与 BOSS 战。反派路线：初始身份抽到【咒灵 / 诅咒师 / 受肉体】即投身反派阵营——主线 BOSS 变为你的队友、原咒术师队友变为敌人；此时作为敌人登场的五条悟，血量为正常的 5 倍。
③ 战斗为 行动序列轮轴制（类星穹铁道）：顶部序列条按综合实力实时推算行动先后，越强越靠前。可开启自动战斗，并支持 1×/2×/3×/5× 倍速。体术按体术区间结算，术式攻击=咒力效率区间×2并消耗咒力（操控越高消耗越低）；术式熟练度达到 100% 可领悟「领域展开」（持续领域；对攻时必中抵消、争夺空间，攻击削弱结界、防御稳固。破域后术式熔断3次自身行动，反转术式缩短至2次；恢复后可再次展开）；每场战斗有 5% 几率领悟被动「反转术式」；「黑闪」可在每场战斗中以 5% 几率自行领悟，京都篇战胜东堂葵则 100% 学会，接触攻击的成功率受控制力、连击与状态影响，触发后进入3次行动的心流并获得短暂领域优势；旧存档成长保留；战斗持续越久双方伤害越高（战意升温），若鏖战过久将按残存战力强制裁决，也可随时点「撤退」主动脱离（标注战败不死/连战的战斗可安全撤离，死斗场撤退等于败亡），绝不平局卡死。右上角可分别开关「音效」与领域/极之番「语音」。
④ 剧情战战败大多即死亡、直接进入结局；少数剧情存在队友救场的续战，以剧情规则为准。高等级队友会主动牵制强敌，残血时请善用「防御」。
⑤ 具名角色登场/胜负时有专属台词（蓝色大字）；五条悟、宿傩、九十九由基等拥有金色大字的专属技能；术式熟练度达 300% 可领悟终极奥义「极之番」（耗半蓝、敌全体500%伤害并回满血，每场一次，金色碎裂震屏；五条悟、十影宿傩、羂索、九十九由基亦会）；「死而替生」被击杀即胜并夺取对方术式，可同时持有多个术式、各自独立熟练度。
⑥ 本作为单机网页游戏，所有数值与剧情均在你的浏览器本地运算。
